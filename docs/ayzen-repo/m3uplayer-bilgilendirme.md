# M3UPlayer Eklentisi Bilgilendirme

M3UPlayer eklentisi Cloudstream uygulamasına M3U veya Xtream listelerini girerek bunları kullanmanızı sağlıyor. Eklentiyi indirdiğinizde sol tarafta çıkan **Ayar** butonu aracılığıyla listelerinizi girebilir, sıralama yapabilir, kategorilendirme yapabilir ve daha bir çok özelliği kullanabilirsiniz.
- Xtream altyapısı kullanan ancak çeşitli değiştirmeler yapan listeler doğal olarak desteklenmeyebilir. Bazı listeleri özel olarak ByAyzen'in eklemesi gereklidir. Kendisine danışmak için Github reposundan issue açabilir yada Kraptor sohbet kanalına katılabilirsiniz.
- Listesiz, tekli M3U'lar desteklenmez. Sadece listeler desteklenir.
